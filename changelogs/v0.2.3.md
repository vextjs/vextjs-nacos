# v0.2.3

**发布日期**：2026-05-13

## 概览

`v0.2.3` 是一次发布收口版本，目标是把 `vextjs-nacos` 与已发布的 `vextjs@0.3.4` 基线对齐，并补齐发版元数据。

## 变更

- 将 `peerDependencies.vextjs` 与开发依赖中的 `vextjs` 最低版本统一提升到 `>= 0.3.4`
- 同步 README 中的安装方式与兼容性说明，明确常规消费场景直接使用 npm semver 依赖即可
- 补齐 `CHANGELOG.md` 与版本发布记录，方便后续按版本线追踪兼容性变更

## 兼容性

- Node.js `>= 18`
- vextjs `>= 0.3.4`
- nacos `^2.6.1`

## 备注

本次版本不调整运行时代码路径，也不引入新的公开 API。
