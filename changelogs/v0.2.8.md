# vextjs-nacos v0.2.8

发布日期：2026-06-15

## 修复

- 修复运行期 Nacos 配置订阅更新时重复调用 `app.extend("remoteConfig")` 导致合法 JSON object 更新无法刷新 `app.remoteConfig` 的问题。
- 修复订阅更新异常日志过粗的问题：解析失败继续输出解析/契约错误，同步失败改为 `Remote config update failed`，不再误导为配置不是 JSON object。
- 开发验证基线升级到 `vextjs@0.3.26`，并使用 npm overrides 固定 `esbuild@0.28.1`，消除 dev 工具链高危 audit 阻断。
